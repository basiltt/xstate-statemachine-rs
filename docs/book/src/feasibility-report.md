# Feasibility report (historical)

The feasibility study that led to this Rust port lives at
[`docs/feasibility-report.md`](https://github.com/basiltt/xstate-statemachine-rs/blob/main/docs/feasibility-report.md)
in the repository. It is historical: it motivated the project and sketched the roadmap before the
five [ADRs](reference/adr.md) were accepted, and some of its numbers and phasing predate the
current implementation.

The ADRs supersede it for anything the two disagree on.
